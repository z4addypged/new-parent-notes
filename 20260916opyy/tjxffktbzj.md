# 医保门诊“亲情付”“家庭共济”怎么操作？

> 更新时间：2026-09-16 (UTC+8)

医保亲情付是基于个人医保账户为家庭成员开设的子账户服务。

家庭共济是职工将本人个人账户资金授权给近亲属使用，用于支付看病买药时个人自付部分。比如父母可以将自己孩子的医保账户绑定亲情账户，再开通家庭共济，孩子就可以使用父母医保账户的资金支付医疗费用。同时可以使用资金支付居民医保费用。

徐矿总医院支持医保“亲情付”看看怎么操作。友情提醒，使用微信登录、支付宝登录会跳转徐矿总医院互联网医院平台后，再进行医保支付，请按提示步骤进行操作。

**如何操作**

一．医院门诊就诊，使用医保卡，电子医保卡前，登录江苏医保云APP，注册后，在家庭共济模块绑定自己的亲属。

二．微信扫码支付

1.扫码添加亲情账户

2. 按提示填写需要添加的家人信息

3.签个人承诺书并签名，提交材料

4授权激活，绑定成功

 友情提醒：绑定成功后，每次直接使用微信扫码即使用亲情账户。

三．使用支付宝扫码支付

1.支付宝首页搜索电子医保，点击添加医保亲情账户。

2. 点击为家人开通，需要准备身份证，出生证明等资料，大于16岁需要孩子刷脸验证，请提前准备好。

3. 按步骤上传资料。

4. 操作完成，提示亲情账户开通成功。

**如何使用**

1.门诊刷孩子的电子医保时，直接亲情账户支付。

2.孩子的手机支付宝扫码直接亲情支付有需要的朋友，快来体验一下吧！
